# Share evidence safely

Do not put credentials, personal data, proprietary app source, unreviewed screenshots or vulnerability details in public Discussions or pull requests.

For a potential security problem, use this repository’s private **Report a vulnerability** channel when available, or contact the maintainer through the contact information on the [maintainer profile](https://github.com/ADIITJ). If no private channel is available, ask for a private contact route without describing the exploit publicly.

Run only trusted application build commands on your machine. Use disposable isolated workers for untrusted projects. Browser sandboxing does not sandbox npm build scripts.

The package does not certify arbitrary untrusted code as safe. Keep dependencies and the installed version under your normal security review. Text redaction does not remove sensitive pixels from screenshots.
